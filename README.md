# Хуификатор

Manifest V3-расширение для Chromium, которое локально добавляет ху-редупликацию к видимому русскому тексту страницы. Данные страницы не отправляются наружу.

## Разработка

```powershell
npm install
npm run check
```

Готовое распакованное расширение создаётся в `dist/`. В Chrome/Edge откройте страницу управления расширениями, включите режим разработчика и выберите «Загрузить распакованное расширение», указав папку `dist`.

## Установка опубликованной версии

1. Откройте последний [GitHub Release](https://github.com/DimonSmart/Huifikator/releases) и скачайте `huifikator-X.Y.Z.zip`.
2. Распакуйте ZIP в отдельную папку.
3. Откройте `chrome://extensions` (или `edge://extensions`), включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку, где находится `manifest.json`.

Обновление выполняется повторной загрузкой новой папки через «Обновить» на странице расширений.

## Выпуск новой версии

На Windows выполните `publish-next-version.bat`. По умолчанию увеличивается patch-версия; доступны также `publish-next-version.bat minor` и `publish-next-version.bat major`. Скрипт создаёт коммит и тег `vX.Y.Z`, отправляет их в GitHub. GitHub Actions соберёт ZIP, прикрепит его к Release и сохранит как артефакт workflow.

Для запуска: откройте обычную веб-страницу, нажмите значок расширения и кнопку «ХУИФИЦИРОВАТЬ». Повторное нажатие восстанавливает текст, если сайт не заменил его после обработки.

## Ограничения MVP

Не обрабатываются iframe, closed Shadow DOM, canvas, PDF, изображения и страницы браузера, запрещающие внедрение скриптов.
