# Хўфикатор

**Хўфикатор** — шуточное Manifest V3-расширение для Chromium, которое локально добавляет ху-редупликацию к видимому русскому тексту страницы. Данные страницы не отправляются наружу.

Для поиска по репозиторию и в поисковых системах также используются варианты написания: **Хуификатор**, **Хуефикатор**, **Huifikator**.

## Установка из готового пакета

Расширение пока не требует публикации в Chrome Web Store или Microsoft Edge Add-ons: после выпуска версии готовый ZIP-пакет прикрепляется непосредственно к GitHub Release этого репозитория.

1. Откройте раздел [Releases](https://github.com/DimonSmart/Huifikator/releases) и выберите последнюю версию.
2. Скачайте файл `huifikator-X.Y.Z.zip` из Assets.
3. Распакуйте ZIP в отдельную папку. Браузер не сможет установить этот ZIP напрямую — ему нужна распакованная папка расширения.
4. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge.
5. Включите **Режим разработчика** (Developer mode).
6. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите распакованную папку, в которой находится `manifest.json`.

Для обновления скачайте ZIP новой версии, распакуйте его вместо старой папки и нажмите **Обновить** на странице расширений либо загрузите новую папку заново.

Для запуска откройте обычную веб-страницу, нажмите значок расширения и кнопку «ХУИФИЦИРОВАТЬ». Повторное нажатие восстанавливает текст, если сайт не заменил его после обработки.

## Немного исторической хуелогии

Слово **«хуй»** появилось сильно раньше интернета, заборов и комментариев на YouTube. Лингвисты реконструируют праславянское `*xujь`; академический **«Этимологический словарь славянских языков»** связывает его со словом **«хвоя»** и более древней семантикой вроде «шипа» или «колючки». Так что ботаника, как обычно, всё начала первой.

А слово совершенно точно не изобрели современные матерщинники. В **псковском Евангелии XIV века** исследователи обнаружили соскобленные обсценные приписки священника Саввы — ранние письменные фиксации соответствующей лексики и средневекового словесного юмора. Всё это не байка из интернета, а статья В. Б. Крысько и И. М. Ладыженского [«Поп-сквернослов: Обсценные маргиналии в древнерусском евангелии»](https://doi.org/10.13173/WS.67.2.286), опубликованная в славистическом журнале *Die Welt der Slaven*.

Ну а представление о матерной брани как об особо запретной разновидности речи тоже формировалось постепенно. Историк и фольклорист А. А. Панченко показывает, что церковные и общественные запреты активно оформлялись в России в XVI–XVII веках, а красивая универсальная теория «это всё древний языческий обряд плодородия» реальностью не подтверждается. См. его академическую статью [«Крестьяне, иконы и матерная брань»](https://doi.org/10.31857/S0869541523020021), *Этнографическое обозрение*, 2023, № 2, с. 21–51.

**Да, ссылки выше — реальные академические источники. Мы проверяли. Учёные действительно исследуют и такое.**

## Разработка

```powershell
npm install
npm run check
```

Готовое распакованное расширение создаётся в `dist/`. Для локальной проверки его можно загрузить через страницу управления расширениями тем же способом: включить режим разработчика и выбрать **Загрузить распакованное расширение**, указав папку `dist`.

## Выпуск новой версии

На Windows выполните `publish-next-version.bat`. По умолчанию увеличивается patch-версия; доступны также `publish-next-version.bat minor` и `publish-next-version.bat major`. Скрипт создаёт коммит и тег `vX.Y.Z` и отправляет их в GitHub. GitHub Actions проверяет и собирает расширение, создаёт `huifikator-X.Y.Z.zip`, прикрепляет его к GitHub Release и сохраняет как артефакт workflow.

## Ограничения MVP

Не обрабатываются iframe, closed Shadow DOM, canvas, PDF, изображения и страницы браузера, запрещающие внедрение скриптов.
